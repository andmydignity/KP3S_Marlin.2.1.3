Used Mechano's config to recompile Marlin 2.1.3-b3, also enabled the brand new FTM-Input shaping (just like in Klipper).
I compiled it for MBL 290C version but you can compile it to your desires by changing the confs.

(FTM_Input shaping is off by default, you can enable it in Setting -> Motion -> Fixed Time Motion in LCD menu)
(Also old ZV based input shaping was disabled to make room for the new one)
